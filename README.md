# Шифр Цезаря
Консольное Java-приложение для шифрования и расшифровки текстовых файлов с помощью шифра Цезаря.

## Возможности

- **Шифрование** — сдвиг символов текста на заданное количество позиций в алфавите.
- **Расшифровка** — восстановление исходного текста с помощью известного ключа.
- **Brute Force** — подбор ключа перебором возможных вариантов, если исходный ключ неизвестен.
- **Работа с файлами** — чтение исходного текста и сохранение результата в отдельный файл.
- **Проверка данных** — обработка некорректных ключей и ошибок при работе с файлами.

## Используемые технологии

- Java 17
- Java NIO (`Path`, `Files`)
- UTF-8

## Структура проекта

```text
src/main/java/com/javarush/caesar/
    MainApp.java
    core/

        BruteForce.java

        Validator.java
    exception/

```

## Запуск программы

1. Склонируйте репозиторий на компьютер.
2. Откройте проект в IntelliJ IDEA.
3. Запустите класс `MainApp`.
4. Следуйте инструкциям консольного меню.

## Использование

Для шифрования и расшифровки укажите путь к исходному файлу, путь для сохранения результата и ключ шифрования.

Для подбора ключа без его знания используйте режим Brute Force.
